# client-comms：讓客戶對話溫暖又有效

這個 skill 處理的是「這句話會不會嚇到人、會不會太推銷、客人已經回話了要怎麼接下去」——是溝通策略和心理層面的判斷，不是語感潤飾（語感潤飾交給 `speak-human-tw`）。

核心判斷來源只有三個，混著用，不是照順序跑過一遍的流程：

## 1. 講真話但不嚇人——非暴力溝通四步驟

要跟客人講命盤裡不好聽的部分、或回覆有情緒的留言時，想這四層，不是逐字套公式：

**觀察**（講事實，不帶評價）→ **感受**（他大概是什麼心情）→ **需要**（他真正在意、想要的是什麼）→ **請求**（一個具體、小、他做得到的下一步）

反例：「你這運勢很差，要趕快處理」——只有判斷，沒有感受也沒有具體請求，聽起來像恐嚇。
改法：「這段時間卡在一個反覆繞不出去的點（觀察），會讓人很挫折、甚至開始懷疑自己（感受）——這種時候通常需要先搞清楚卡點在哪（需要），要不要花 20 分鐘讓我幫你看一下盤，先搞清楚方向（請求）」

## 2. CTA 怎麼寫才不像推銷——蔡康永「把對方放在心上」

寫 CTA 之前，先想「這句話讀者聽起來是什麼感覺」，不是「我想講什麼」。實際落地成三個檢查：

- **疑問句優先於命令句**：「想知道的話可以私訊我」比「私訊我」溫和
- **留退路，不用「一定」「保證」**：「我幫你看看方向」比「我保證幫你解決」更可信，也更符合起卦本來就會隨狀態變動的事實
- **請求要具體到對方不用猜下一步**：「私訊我『守護神明』」比「有興趣的話歡迎私訊」清楚——含糊的 CTA 反而會讓人不知道要做什麼而放棄

## 3. 詞語微調——Jonah Berger《如何讓人聽你的》

同一個意思，換幾個字就會差很多。常用的幾個方向：

- **主動句 > 被動句**、**問句 > 直述句**（問句會讓人更想往下讀、更想回答）
- **「已經有人」類的社會證明**比「建議你」更容易推人一下（例如「選這個的人剛好最近都卡在⋯」比「你可能也是⋯」更自然）
- **「你可以」取代「你應該／你一定要」**：前者給選擇感，後者像在教訓人
- 這些是微調，不是重寫整句的理由——原意、原語氣不能因為套公式而走味

## 4. 同一人不要被同一句 CTA 催兩次

這是這次實際踩過的坑：ManyChat 自動 DM 已經問過客人「私訊我『守護神明』」一次，如果客人後來在留言區回了一尊神明，公開留言回覆**不要再重複同一句 CTA**——等於同一個人被推銷兩次，容易顯得在追著他跑。

動筆前先問一句：**這個人在這個漏斗裡，是不是已經在別的接觸點（DM、上一輪留言、客服訊息）被問過同一件事？**
- 還沒問過 → 這裡可以放 CTA
- 已經問過 → 這裡只做呼應／拉近關係，CTA 交給還沒問過的那個接觸點去做，真正有興趣的人會自己往下走，不用每個接觸點都催一次

## 5. 先判斷：這個客人還能接住，還是已經「怎樣都有話說」

上面 1-3 條是用來接住「還願意繼續聊」的客人——他有疑惑、有情緒，但解釋、接住感受之後有機會往下走。但有一種客人不是這樣：不管妳怎麼解釋、怎麼調整說法，他都會換一個角度繼續挑（這次說不準，妳解釋了就說妳功力不夠，再解釋又挑別的），這種是在找情緒出口，不是真的要答案。

判斷方式：**如果同一件事妳已經認真解釋一輪，他還是繼續換角度挑毛病**，就是進入這種模式了，不是「再解釋一次、再放軟一點」就能解的。

這種情況下，繼續用非暴力溝通的方式解釋、道歉或放軟，反而會被當成示弱或心虛，讓對方更有空間繼續挑。該做的是**一句平靜、不防衛、不升級的收尾句**，然後停下來，不用追著把話說開、不用求對方認同：

> 「我也沒有想要跟你爭，先這樣吧」

這句話的重點：不反駁他的指控（不說「我沒有功力不夠」）、不道歉討好、也不甩門（不說重話）——單純把這段對話收掉。收尾之後不用主動追問或道歉，讓它自然停在那裡就好。

## 寫作時沒講清楚的情境，先問一句再動筆

不確定這段文字會出現在漏斗的哪個位置（是第一次接觸，還是客人已經被問過一次了？）時，先問 KK 一句「這是客人第一次收到訊息，還是已經有別的接觸點問過類似的事？」，不要自己假設，因為這直接決定要不要放 CTA。

## 輸出方式

直接寫出可以複製貼上的成品，不是列一堆選項讓 KK 自己選。寫完之後，用一句話講這次主要用了上面哪個判斷（例如「這裡拿掉 CTA 是因為 DM 已經問過一次」），讓 KK 看得懂邏輯、不只是拿到文字。

- 全程繁體中文，中文遇英文/數字加半形空格
- 語氣自然像朋友對話，少用「旨在」「總的來說」這類生硬詞
- emoji 點到為止，不轟炸
- 「起卦才知道答案、守護神明會隨狀態變動」這類紅線本來就是 KK 的既定規則，文案裡不要因為套了溝通公式就寫成確定答案或暗示免費解答
